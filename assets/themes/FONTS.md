# Fonts in the theme art

GitHub shows these SVGs as images, and an image cannot load a font from
elsewhere. Each file therefore carries a small subset of the fonts it uses,
limited to the characters in that file. `field-dossier` embeds no font.

Reserved Font Name. The embedded files are glyph subsets, the same kind of file
a web-font service serves.
